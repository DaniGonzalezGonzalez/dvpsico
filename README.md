# dvpsico

**dvpsico** es una proyecto de la divulgación sobre temas relacionados con la psicología, la neurociencia y tecnología. El objetivo de esta web es centralizar y compartir información útil y accesible para toda la gente que le interesa el proyecto.

## 📚 ¿Qué encontrarás en la web de dvpsico?

- **Información sobre el proyecto**: introduciendo el propósito de los diferentes canales de divulgación.
- **Programas**: un carrusel de información básica sobre las categorías en que agrupamos los vídeos y podcast. Inmediatamente debajo, un botón con más información
- **Horario**: información sobre los horarios del canal de directos, para que no te pierdas nada.
- **Apoyo**: zona donde se muestrasn las diferentes formas de apoyar al proyecto.
- **Agradecimientos**: carrusel con información de los diferentes agradecimientos para la gente que decide aportar económicamente, y un botón de acceso al listado de dichas personas.

## ⚙️ Tecnologías Utilizadas

Este proyecto está construido utilizando las siguientes tecnologías:

- **Frontend**: React, Tailwind CSS, HTML, CSS, Javascript
- **Backend**: Supabase (Base de datos y autenticación)
- **Otros**: Apoyo con diferentes IAs en la elaboración de funciones y componentes.

## 🤝 Gratuito e informativo

Todo el contenido de esta web está desmonetizado y es de carácter informativo.
